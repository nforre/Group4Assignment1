# Group4Assignment1
Group 4's Java Assignment 1 for CS 3354 Fall 2026

# Program Description
This program simulates a grocery inventory management system. The program allows
you to print item inventory and restock items through a menu interface.

# How to run 
1. Clone the repository
2. Run the groceryManager.java file in a compiler of your choice.
3. Follow the menu directions to use the program.
